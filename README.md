# Library Management System

**Name:** Gizem Su Kaplan  
**Course:** Database Systems (21001)

## 1. Project Description

This project is a simple Library Management System using Python, SQLite, HTML, CSS, and JavaScript.

The purpose of this project is to manage books, library members, and borrowing records using a database.

## 2. Main Features

- Add new books
- Add library members
- Search books by title or author
- Borrow and return books
- Check available and borrowed books
- View borrowing history
- View basic library reports

## 3. Technologies Used

- Python: Backend and web server
- SQLite: Database
- HTML: Website structure
- CSS: Website design
- JavaScript: Website interactions
- SQL: Database queries

## 4. Project Files

- `app.py` — Main Python application
- `interface.html` — Website interface
- `schema.sql` — Database tables
- `library.db` — SQLite database

## 5. How to Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Run the following command:

   `python3 app.py`

4. Open this address in your browser:

   `http://127.0.0.1:8765`

## 6. Database

The project uses three main tables:

- **Books:** Stores book information.
- **Members:** Stores library member information.
- **Loans:** Stores borrowing and return records.

These tables are connected using primary keys and foreign keys.

This project helped me practice SQL queries, database relationships, and connecting a database to a simple web application.
